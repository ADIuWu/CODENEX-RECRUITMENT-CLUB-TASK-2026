# 🗓️ EventHub - Campus Events Platform

Welcome to **EventHub**, a centralized platform built to replace cluttered WhatsApp groups and messy Google Forms for campus events. This project was developed as part of the first-year club selection task.

## 🎨 Dual Themes Included
To demonstrate versatility in UI/UX design, this repository contains two completely different stylistic versions of the app:
* **☀️ Clean Campus Edition:** A highly professional, minimalist, Notion-style interface with a focus on clean typography, standard shadows, and intuitive layout.
* **🌑 Midnight Glass Edition:** A modern, sleek dark mode theme featuring glassmorphism (frosted glass), glowing gradient text, and polished hover animations. 

## ✨ Core Features
This application successfully fulfills all mandatory requirements from the task sheet:
* **Discover Events:** A dynamic feed of all upcoming campus activities.
* **Search & Filters:** Instantly search by keyword or filter by categories (Tech, Cultural, Sports).
* **Event Details & Registration:** View event info and register with a single click.
* **Registration Count:** Real-time tracking of how many students are attending.
* **My Events:** A dedicated dashboard for events you have saved or registered for.
* **Create/Delete Events:** Form to deploy new events to the main feed, and the ability to purge them.
* **Save Events:** Bookmark interesting events for later.

## 🍪 Brownie Points Achieved
This project includes several extra features to secure brownie points:
* **Simulated Authentication System:** A fully functioning frontend login system requiring Name, Reg No, Email, and Password. Users cannot register or create events without authenticating first.
* **QR Ticket Generation (Unasked Feature):** Upon registration, the app dynamically generates a personalized QR code ticket displaying the user's Name and Registration Number.
* **Google Calendar Integration (Unasked Feature):** A 1-click button to automatically draft the event into the user's Google Calendar.
* **Exceptional UI/UX:** Built with Tailwind CSS, featuring responsive design, smooth hover animations, conditional rendering, and modal popups.
* **Clever Engineering:** Engineered as a single-file application utilizing Vanilla JavaScript and the browser's `localStorage`. It features complex array filtering, state management, and data persistence without requiring a backend server.

## 💻 Tech Stack
* **Frontend:** HTML5, Vanilla JavaScript (ES6+)
* **Styling:** Tailwind CSS (via CDN)
* **Icons:** FontAwesome
* **APIs Used:** QR Server API (for dynamic ticket generation)
* **Database:** Browser `localStorage` (Mock DB)
